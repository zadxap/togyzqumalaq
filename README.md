# Тоғызқұмалақ онлайн

**Онлайн-платформа национальной казахской манкалы Тоғызқұмалақ**: матчи 1×1 в реальном
времени, ИИ-противник, рейтинг Эло, зрители, история партий. PWA.

> Проект по дисциплине **В06.075 «Бұлтты және мобильдік технологиялар»**.
> Тема: национальная игра в облаке — real-time мультиплеер на Supabase.

## Что внутри

- **Движок правил** — чистый TypeScript, полностью по официальным законам
  (WTKF): раздача против часовой с возвратом первого камня, правило одного
  камня, захват чётных последним камнем, **туздык** (3 камня; запреты: лунка №9,
  один за партию, «одноимённая»), **атсырау** (дополнительный ход соперника и
  сбор доски), победа при казане 82+, ничья 81:81. 26 юнит-тестов + 300
  случайных партий с проверкой сохранения камней.
- **ИИ-противник** — minimax с альфа-бета отсечением и итеративным углублением
  в **Web Worker** (UI не замирает). 3 уровня глубины: 2 / 4 / 7. Это не модель
  и не нейросеть — детерминированный поиск: мгновенно, офлайн, всегда легальные
  ходы. Обыгрывает случайного игрока 5:0.
- **Онлайн-матчи** — Supabase Realtime (`postgres_changes`): позиция матча хранится
  в jsonb, каждый ход = UPDATE, который прилетает сопернику и зрителям живьём.
  Анимация раздачи камней по одному (движок возвращает пошаговый trace).
- **Лобби** — открытые вызовы и живые матчи, обновляются в реальном времени.
- **Рейтинг Эло** (K=32) обновляется участниками при завершении матча.
- **Зрители** — presence-канал матча, счётчик онлайн-наблюдателей.
- **Вход** — magic link (письмо на почту) или гостевой режим (anonymous sign-in).
  Профиль создаётся триггером в БД.
- Двуязычный интерфейс **қазақша / русский**, PWA (установка на телефон).

## Стек

React 19 + TypeScript + Vite 7 · Supabase (Postgres + Realtime + Auth) ·
vite-plugin-pwa · Vitest · GitHub Actions · шрифты self-hosted (cyrillic-ext —
ә, ғ, қ, ң, ө, ұ, ү, і).

## Архитектура

```
React (PWA) ──── ход: PATCH matches.position (jsonb) ────▶ Postgres
     ▲                                                        │
     └── Realtime onSnapshot-аналог: postgres_changes UPDATE ◀─┘
            (соперник + зрители получают позицию и анимируют раздачу)

ИИ: Web Worker, minimax(depth≤7, alpha-beta, время ≤1.6 c)
```

### Структура БД

```
profiles (id ← auth.users, display_name, elo, wins/losses/draws)
matches  (id, status waiting|playing|finished, player0, player1,
          position jsonb, outcome p0|p1|draw, move_count, last_move)
```

RLS: читать — всем вошедшим (лобби и зрители), создавать — первый игрок,
обновлять — участники и присоединяющийся к `waiting`, удалять — автор
незанятого вызова. `profiles` пишет только владелец.

## Правила — кратко

- 18 лунок × 9 камней, казаны пусты. Ход: все камни из своей лунки, первый —
  обратно в неё, по одному против часовой (свои 9 → лунки соперника 1..9).
- Лунка с 1 камнем: камень перекладывается соседу.
- Последний камень в лунке соперника: чётное количество → захват всех в казан;
  ровно 3 → туздык (лунка захватывается, её дальнейшее содержимое — твоё).
- Нельзя: туздык на лунке №9 соперника, второй туздык за партию, «одноимённый»
  (зеркальный) туздыку соперника.
- Атсырау: сопернику нечем ходить → ты делаешь один лишний ход → если нечем
  осталось, доска разбирается по сторонам. Больше камней — победа, 81:81 — ничья.

## Локальный запуск

```bash
npm install
cp .env.example .env     # вписать URL и anon key проекта Supabase
npm run dev              # → http://localhost:5173
npm test                 # 32 теста: движок + ИИ
```

## Supabase

1. [supabase.com](https://supabase.com) → New project
2. Project Settings → API → скопировать URL и anon key в `.env`
3. Authentication → Sign In/Up → включить **Anonymous sign-ins** (для гостей)
4. Миграции: `supabase link --project-ref <ref>` → `supabase db push --remote`
   (нужен access token: Dashboard → Account → Access Tokens)

## Деплой (Vercel)

1. Import Git Repository → `zadxap/togyzqumalaq` (Vite определится сам)
2. Environment Variables: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`
3. Deploy. Готово — вход по magic link работает сразу.
